Notes on the readings

How to read these numbers

  1. The official board has added no model since 3 Sep 2026 (GPT-6 Astra; its runs finished on 1 Sep).3 Its data file was regenerated on 22 Sep with no new runs.5 A GitHub issue on the benchmark's repository quotes Datacurve's CEO saying the team is building the next version.41
  2. Epoch AI's review of 7 Sep 2026 rated DeepSWE 1.1 'flawed', finding grading defects in 23 of 113 tasks, mostly hidden tests colliding with tests the agent wrote.39 Tokenless separately documented 70 ways a submission can rewrite test outcomes.40 Treat differences of a few points with care.
  3. Lab claims are run by the lab, on its own harness, effort settings and trial count, so they are not directly comparable with the official runs (mini-swe-agent, four passes over 113 tasks).4 The harness is listed on every row. xAI says Datacurve ran the Grok 4.7 evaluation for it, though the result never appeared on the public board.24
  4. Independent runs come from Mercor (mini-swe-agent, 500 steps, 2-hour limit, 3 passes),37 Artificial Analysis (Grok Build harness),36 Fireworks (Kimi K3 at three effort levels)28 and entrpi (MiniMax M3).35
  5. Costs are per task in USD. The official page and its data file disagree for 19 of 70 configurations; this tracker shows the page's figure and keeps the file's in the row notes.5 Lab costs are the lab's own, shown only where the lab published them.
  6. Mercor shows no date for each model, so a model whose only result is Mercor’s appears only when the release slider is at any time.37
  7. A number is included only when it was read at the source that published it. Figures that appear only on aggregator sites are left out; research/ingest-log.txt in the repository lists each one and why.
  8. Anthropic has published no DeepSWE 1.1 score for Claude Haiku 5.5;34 Mercor's independent run is the only one. There is no GPT-6.1 Luna: OpenAI released GPT-6.1 Sol only.31
  9. Where a source published token counts but no cost, the cost is estimated from Vercel AI Gateway’s list prices and shown as a range marked est.42 With only a total token count, the range runs from every token priced as input to every token priced as output; cached input is cheaper still, so the true cost may sit below it. No reading qualifies today: Poolside’s token counts for Laguna S 2.1 are output tokens only, and an agent’s cost is mostly its input.
  10. DeepSeek re-released V4 Pro (as 0813) and V4 Flash (as 0731) under the same names; the official board’s live rows are the re-releases, and the earlier previews are listed as separate models.12 Gemini 3.1 Pro was only ever released as a preview, so Mercor’s “Gemini 3.1 Pro” is the same model as the board’s.
Methods

How this was made

What was gathered
On 9 Oct 2026, Claude (Anthropic’s model) ran Dossier’s free local research loop with its own web search: six search tasks covering the official board, the US labs, Chinese and open-weight labs and Mistral, aggregator sites, and community and press coverage. A separate fact-check pass then settled the conflicts between them. No paid research API was used. A second sweep on 10 Oct searched the labs’ pages, independent evaluators and archived copies of the official board for other effort levels of the 53 models recorded at only one; it found one (Laguna S 2.1 with thinking off) and separated DeepSeek’s V4 previews from their re-releases.
What was kept
The two sweeps returned 623 raw figures. 215 readings of 80 models survived the rule that a number is read at the source that published it, and the page cites 42 sources in the list below. Official rows are re-read from the board’s own page every day.
What was verified
Every lab figure was re-read on the lab’s own page or PDF. Three conflicts were settled against the primary document: GPT-6.1 Sol’s xhigh and max scores, who published Grok 4.7’s 73%, and the harness behind Muse Spark 1.3. Of the 22 sources the research report cites, none were fabricated; two OpenAI pages block automated reads and one StepFun page did not load.
Release dates
The release slider uses the date a model’s source states for its release where one does, and otherwise the date its first DeepSWE 1.1 result was published: the launch post for a lab’s own score, or the day the official board first listed it. Labs publish these scores at launch, so for new models the two agree. Models whose only result is undated, such as most of Mercor’s, appear only when the slider is at any time.
What could not be established
When each model joined Mercor’s board; cost per task for Anthropic, Google and Meta models, which those labs do not publish; a dated StepFun page for Step 5 Preview; and why Datacurve ran Grok 4.7 without posting the result. No person has yet re-checked every row; corrections are welcome as issues on the repository.
